# Contributing

[English](CONTRIBUTING.md) | [简体中文](CONTRIBUTING.zh-CN.md)

Report problems with catalog entries, installation instructions, language links, or the skill's decisions through GitHub Issues. Include your agent, operating system, request, expected behavior, and actual result. Redact private paths and credentials.

For changes, open a pull request explaining the problem and how you checked the result. Keep English and Chinese documentation consistent. Preserve the distinction between downloading and installing, and avoid claiming this skill is a background watcher.

Check Markdown links and the SKILL.md frontmatter. When changing deduplication behavior, verify that reinstalling an item updates its entry while preserving notes and the original date. No executable runtime is included in this repository.
